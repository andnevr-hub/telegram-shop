# 🛒 ChiSetupShop — Повна інструкція налаштування (з Supabase)

---

## Що ти отримуєш

- **Telegram Mini App** — магазин для покупців (мишки, клавіатури, навушники, килимки)
- **Адмін-панель** (`/admin`) — керування товарами та замовленнями
- **Telegram-бот** — миттєві сповіщення про нові замовлення
- **Supabase** — безкоштовна база даних + сховище фото, **дані НЕ зникають** при перезапуску сервера

---

## КРОК 1 — Створи Telegram-бота

1. Відкрий Telegram → знайди **@BotFather**
2. Надішли `/newbot`
3. Придумай назву: наприклад `ChiSetupShop`
4. Придумай username: наприклад `chisetupshop_bot`
5. **Збережи токен** — виглядає так: `1234567890:ABCDEFabcdef...`

---

## КРОК 2 — Дізнайся свій Telegram ID

1. Відкрий @userinfobot в Telegram
2. Надішли `/start`
3. Бот відповість: `Id: 123456789` — **збережи цей номер**

## КРОК 3 — Створи проєкт Supabase (база даних + фото)

1. Зайди на **supabase.com** → **Start your project** → зареєструйся (можна через GitHub)
2. **New Project**:
   - **Name:** `chisetupshop`
   - **Database Password:** придумай і **збережи** надійний пароль
   - **Region:** Frankfurt (EU Central) — найближче до України
3. Натисни **Create new project**, зачекай ~2 хвилини

### 3.1 — Створи таблиці

1. Зліва обери **SQL Editor** → **New query**
2. Встав цей код і натисни **Run**:

```sql
create table products (
  id bigint generated always as identity primary key,
  name text not null,
  category text not null,
  price integer not null,
  stock integer default 0,
  description text,
  specs jsonb default '[]',
  photo text,
  created_at timestamp with time zone default now()
);

create table orders (
  id bigint generated always as identity primary key,
  order_num text unique not null,
  customer_name text,
  customer_phone text,
  delivery_type text,
  delivery_city text,
  delivery_branch text,
  payment_type text,
  items jsonb not null,
  total integer not null,
  status text default 'new',
  created_at timestamp with time zone default now()
);

alter table products enable row level security;
alter table orders enable row level security;

create policy "Public read products" on products for select using (true);
create policy "Service role full access products" on products for all using (true);
create policy "Service role full access orders" on orders for all using (true);
```

Має написати **Success. No rows returned** — це нормально, таблиці створені.

### 3.2 — Створи сховище для фото

1. Зліва обери **Storage** → **New bucket**
2. **Name:** `product-photos`
3. Постав галочку **Public bucket** (щоб фото відкривались в магазині)
4. Натисни **Create bucket**

### 3.3 — Отримай ключі доступу

1. Зліва обери **Project Settings** (іконка шестерні) → **API**
2. Знайди і скопіюй:
   - **Project URL** — виглядає як `https://xxxxx.supabase.co`
   - **service_role key** (НЕ anon key!) — довгий рядок що починається з `eyJ...`

⚠️ **service_role key** дає повний доступ до бази — нікому не показуй і не публікуй на GitHub!

## КРОК 5 — Задеплой на Render

1. Зайди на **render.com** → зареєструйся
2. **New +** → **Web Service** → підключи GitHub → обери репозиторій
3. Заповни:
   - **Region:** Frankfurt (EU)
   - **Root Directory:** `chisetupshop` (якщо проєкт у підпапці репозиторію)
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
   - **Instance Type:** Free

4. Прокрути до **Environment Variables** → додай:

| Key | Value |
|-----|-------|
| `BOT_TOKEN` | токен від BotFather |
| `ADMIN_CHAT_ID` | твій Telegram ID |
| `ADMIN_PASSWORD` | придумай пароль для адмінки |
| `SUPABASE_URL` | Project URL з Supabase |
| `SUPABASE_SERVICE_KEY` | service_role key з Supabase |

5. Натисни **Create Web Service** → чекай 2-3 хвилини
6. **Збережи URL сайту** — типу `https://chisetupshop.onrender.com`

Замовлення приходять у Telegram автоматично:

```
🛒 НОВЕ ЗАМОВЛЕННЯ CS-123456

👤 Клієнт: Іван Іваненко
📞 Телефон: +380 99 999 9999

Товари:
• ATK F1 V2 ×1 = 2 900 ₴

Сума: 2 900 ₴

Доставка: 📦 Nova Poshta
🏙 Київ, Відділення №5
Оплата: 💳 Карта (передоплата)
```

В адмінці (/admin → Замовлення) можна змінювати статус: 🟡 Нове → 🔵 Підтверджено → 📦 Відправлено → ✅ Виконано (або ❌ Скасовано).

## Чому це рішення надійне і безкоштовне

- **Render Free** — хостить сам сервер (засинає без активності, прокидається ~30 сек)
- **Supabase Free** — 500 МБ бази даних + 1 ГБ сховища фото — назавжди безкоштовно, дані **ніколи не стираються** при засинанні Render
- Товари, фото і замовлення живуть в Supabase, а не на диску Render — тому проблема зі зникненням товарів **повністю вирішена**

---

## Додаємо новий товар

1. Адмінка → Товари → "+ Додати товар"
2. Заповни назву, категорію, ціну, кількість, опис, характеристики
3. Завантаж фото
4. Зберегти — товар одразу зберігається в Supabase і з'являється в магазині
