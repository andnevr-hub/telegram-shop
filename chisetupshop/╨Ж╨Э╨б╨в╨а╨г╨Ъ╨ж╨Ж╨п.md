# 🛒 ChiSetupShop — Повна інструкція налаштування

---

## Що ти отримуєш

- **Telegram Mini App** — магазин для покупців (мишки, клави, навушники, килимки)
- **Адмін-панель** (`/admin`) — керування товарами та замовленнями
- **Telegram-бот** — миттєві сповіщення про нові замовлення
- **База даних SQLite** — всі товари та замовлення зберігаються на сервері

---

## КРОК 1 — Створи Telegram-бота

1. Відкрий Telegram → знайди **@BotFather**
2. Надішли `/newbot`
3. Придумай назву: наприклад `ChiSetupShop`
4. Придумай username: наприклад `chisetupshop_bot`
5. **Збережи токен** — він виглядає так: `1234567890:ABCDEFabcdef...`

---

## КРОК 2 — Дізнайся свій Telegram ID

1. Відкрий @userinfobot в Telegram
2. Надішли `/start`
3. Бот відповість: `Id: 123456789` — **збережи цей номер**

---

## КРОК 3 — Завантаж проєкт на GitHub

1. Зайди на https://github.com і створи акаунт (якщо немає)
2. Натисни `+` → `New repository`
3. Назви: `chisetupshop`, зроби **Private**
4. Встанови Git на комп'ютер: https://git-scm.com
5. Відкрий термінал в папці проєкту і виконай:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ТВЕ_ІМ'Я/chisetupshop.git
git push -u origin main
```

---

## КРОК 4 — Задеплой на Render

1. Зайди на https://render.com і зареєструйся
2. Натисни **New +** → **Web Service**
3. Підключи свій GitHub акаунт → обери репозиторій `chisetupshop`
4. Заповни поля:
   - **Name:** chisetupshop (або будь-яке)
   - **Region:** Frankfurt (EU)
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
   - **Instance Type:** Free

5. Прокрути вниз до **Environment Variables** і додай:

| Key | Value |
|-----|-------|
| `BOT_TOKEN` | токен від BotFather |
| `ADMIN_CHAT_ID` | твій Telegram ID |
| `ADMIN_PASSWORD` | придумай пароль для адмінки |
| `APP_URL` | залиш порожнім поки |

6. Натисни **Create Web Service**
7. Чекай ~2-3 хвилини поки деплой завершиться
8. **Збережи URL сайту** — він виглядає як `https://chisetupshop.onrender.com`

---

## КРОК 5 — Оновлюємо APP_URL

1. В Render → Environment → додай:
   - `APP_URL` = `https://твій-сайт.onrender.com`
2. Сервіс перезапуститься автоматично

---

## КРОК 6 — Налаштуй Mini App у BotFather

1. Відкрий @BotFather
2. Надішли `/mybots` → обери свого бота
3. Натисни **Bot Settings** → **Menu Button** → **Edit Menu Button URL**
4. Введи URL свого сайту: `https://твій-сайт.onrender.com`
5. Потім **Edit Menu Button Name** → напиши `🛒 Магазин`

Тепер у бота буде кнопка меню що відкриває магазин!

---

## КРОК 7 — Провір що все працює

### Перевір магазин:
- Відкрий свого бота в Telegram
- Натисни кнопку меню `🛒 Магазин`
- Повинен відкритись магазин з демо-товарами

### Перевір адмінку:
- Відкрий браузер: `https://твій-сайт.onrender.com/admin`
- Введи пароль який ти задав в `ADMIN_PASSWORD`
- Повинна відкритись панель з товарами та замовленнями

---

## КРОК 8 — Додай свої товари

В адмінці (`/admin`):
1. Натисни **Товари** в меню
2. Натисни **+ Додати товар**
3. Заповни:
   - **Назва** — повна назва товару
   - **Категорія** — Мишки / Клавіатури / Навушники / Килимки
   - **Ціна** — в гривнях
   - **Наявність** — кількість в наявності (0 = немає)
   - **Опис** — детальний опис
   - **Характеристики** — натисни "+ Додати рядок" і вводь параметри
   - **Фото** — завантаж фото товару (до 5 МБ)
4. Натисни **Додати товар**

## Важливі нотатки

### Безпека
- **Ніколи не постав `ADMIN_PASSWORD` в публічному репозиторії!**
- `.env` файл є в `.gitignore` — він не завантажується на GitHub

### Render безкоштовний план
- Сервіс "засинає" через 15 хвилин без запитів
- Перший запит після сну займає ~30 секунд
- Щоб уникнути — можна використати https://uptimerobot.com (безкоштовний)
- Або перейди на платний план Render ($7/міс)

### Фото товарів
- На безкоштовному Render **фото видаляються при кожному деплої**
- Для постійного зберігання фото використовуй [Cloudinary](https://cloudinary.com) (безкоштовно 25GB)
- Або просто завантажуй фото знову після оновлень
